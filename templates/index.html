Sobre o projeto

Um projeto de um aluno, pensado para todos

O {{ nome_site }} é um projeto desenvolvido por Gonçalo Lapa com um objetivo simples: ajudar cada pessoa a conhecer-se melhor, explorando as suas próprias ideias, valores e convicções políticas.

Aqui não há respostas certas nem erradas. Há perguntas que convidam a pensar, resultados explicados passo a passo e informação apresentada de forma clara e imparcial, para que cada pessoa tire as suas próprias conclusões.

Perceber em que acreditamos, e porquê, é o primeiro passo para conversar melhor com quem pensa de forma diferente.

Claro

Linguagem simples e direta, sem jargão. Cada conceito é explicado quando aparece.

Educativo

Mostramos como cada resultado é calculado, para perceberes o porquê e não apenas o quê.

Imparcial

Nenhuma ideologia é apresentada como certa ou errada: os resultados descrevem, não julgam.

Privado

As respostas não são guardadas em nenhuma base de dados nem associadas a ti: servem só para calcular o teu resultado.
